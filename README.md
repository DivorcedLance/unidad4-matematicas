# Unidad 4: Teoría y Ejercicios

Página de estudio del propedéutico de matemáticas (Unidad de aprendizaje 4): parábolas, circunferencias y oferta y demanda.

Cada tema tiene tres pestañas:

- **Teoría**, con ejemplos cortos.
- **Ejercicios resueltos** de la unidad, paso a paso, con los errores de la unidad señalados.
- **Ejemplos** de práctica con resultados exactos, dos por cada ejercicio.

La página está en `web/` y se publica en GitHub Pages con la acción `.github/workflows/pages.yml`.
